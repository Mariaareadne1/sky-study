# SKY STUDY — draw with atmosphere

Draw a line in the sky; it becomes a volumetric, physically lit cumulus cloud. Move clouds through real 3D space, push them into the distance, and change the time of day from dawn to moonlight.

_Work in progress — see [PROGRESS.md](PROGRESS.md)._

## Run

```bash
npm install
npm run dev        # http://localhost:5362
```

`/spike.html` is the deterministic render harness (e.g. `/spike.html?preset=golden&shapes=wave,heart&quality=high`).
